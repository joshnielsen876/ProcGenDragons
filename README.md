# ProcGenDragons

A browser game in the making: expeditions into procedurally generated fantastical ecosystems to find and photograph remarkable mythical creatures. Each run seeds a fresh version of an ecosystem, the creatures grow from seeded genomes, and the photos you bring back unlock new tools (lures, flash, long lens, sonar, camouflage, gliders) that open up rarer creatures and harder places.

The project takes its technical approach from the wave of single-file WebGPU worlds that started with [Abyssal Garden](https://github.com/Noniv/abyssal-garden) (MIT): everything is generated by code at load time, with no image, model or sound files.

## Creature Lab

`creature-lab/` is the first prototype. It answers the riskiest question first: can procedural creatures look remarkable enough to be worth photographing?

- **Genome** (`src/genome.js`): a seed becomes a set of numbers and choices: body plan (serpent, ray, drake, medusa), proportions, fins and wings, tail, horns, whiskers, lures, eyes, pattern, palette, glow and motion. Rare traits (Luminous, Crowned, Lantern-bearer, Twin-tailed, Many-finned, Pale, Gilded, Voidborn) carry rarity weights, and their combined rarity sets the tier from Common to Mythic.
- **Body** (`src/body.js`, `src/mesh.js`): the genome becomes geometry. A cross-section is swept along a curved spine, and membranes, horns, whiskers, finger bones, eyes and lures are attached along it. Every vertex records where it sits on the body, so the shader can animate it.
- **Skin and motion** (`src/shaders.js`): WGSL shaders paint stripes, spots, rings or scales, glowing markings that pulse from head to tail, iridescence and light passing through fins. A swimming wave travels down the spine, wings beat, jelly bells contract and tentacles drift, all on the GPU in one draw call per creature.
- **Lab page** (`index.html`, `src/lab.js`, `src/renderer.js`): a grid of specimens on one shared WebGPU canvas. Open one to turn it, zoom, change any gene with sliders, mutate it, or copy its seed. "Hunt for rarities" rolls thousands of seeds and shows only Rare and Mythic finds. A link ending in `#s-<seed>` opens that specimen directly.

### Run it

The lab uses ES modules, so serve the folder instead of opening the file directly:

```
cd creature-lab
python3 -m http.server 8000
```

Then open http://localhost:8000 in desktop Chrome or Edge (WebGPU is required).

`?offscreen` renders into an offscreen texture instead of the page canvas. Automated screenshot checks use it in headless browsers, where presenting a WebGPU canvas is not supported, and read frames back through `window.__lab.capture()`.

## Creature Dive (creatures in Abyssal Garden)

`ocean/` is a copy of [Abyssal Garden](https://github.com/Noniv/abyssal-garden) by Maksymilian Dendura (MIT, see `ocean/LICENSE-abyssal-garden`) with the creature lab's creatures swimming in it. Its own code is unchanged apart from a few hooks:

- `ocean/build.mjs` bundles the creature lab's genome, body and WGSL library into a `LAB` namespace ahead of the world's own files, so the single-file build stays self-contained.
- `ocean/src/creatures.js` places eighteen seeded creatures (serpents, drakes, rays and jellies) on looping paths near the six viewpoints and draws them in the world's scene pass. They share its camera, depth buffer, sunlight, shadows, caustic ambient light and fog, so they sit in the water like the native mantas and fish.
- `ocean/src/main.js` calls `setupCreatures`, draws them after the fish, and shows a field-journal readout naming the creature at the centre of view with its rarity and distance.

Build it with `npm install` and `npm run build` inside `ocean/`, then open `ocean/index.html` in desktop Chrome or Edge. Keys 1 to 6 jump between viewpoints.

## Next steps

1. Tune the creatures until they look striking from every angle, and add more body parts per ecosystem.
2. Add behaviors: wander, curiosity, flee, schooling, feeding and display moods, with the rare moods worth more in photos.
3. Place creatures in an Abyssal Garden style world and add the camera with photo scoring.
4. Build the expedition loop: limited film and oxygen, a field journal, and the first unlockable tool.
